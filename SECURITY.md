# Security

If you believe you have found a security or privacy issue in this project, please report it privately rather than in a public issue:

- Preferred: GitHub → **Security** tab → **Report a vulnerability** (private advisory).

Please include steps to reproduce and the devices/browsers involved. This is a personal, unpaid project with no security team, bug bounty, or commitment to respond or to fix any issue within any timeframe.

Please note that, by design, messages are transmitted locally as sound and can be received by any nearby device running the app. This is expected behaviour, not a vulnerability — see the Terms of Use at https://0pn.ai/#terms.
