# Contributing

Thanks for your interest in improving No Internet Messenger. This is a personal project maintained in spare time; issues and pull requests may be closed, left open, or go unanswered, and nothing here creates any obligation to respond, review, merge or fix.

## Reporting bugs

Open an issue using the bug template. Because this app depends on each device's speaker and microphone, please include: both devices and browsers (with versions), the distance between them, whether the room was quiet or noisy, and what you saw on each screen.

## Suggesting features

Open an issue using the feature template. Keep the product promise in mind: no accounts, no servers, nothing leaves the device, and a UI that stays simple.

## Pull requests

1. Fork the repository and create a branch from `master`.
2. Keep `index.html` self-contained: no build step, no external scripts, fonts or stylesheets.
3. Test on at least one phone and one computer, in a real room, before opening the PR.
4. Describe what changed and why. Small, focused PRs are reviewed faster.
